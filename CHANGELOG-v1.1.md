# v1.1 — Постоянная калибровка (Vercel KV) + полный бэктест

## Что нового

### Персистентная калибровка через Vercel KV
Параметры Platt-калибровки `(A, B)` теперь сохраняются в Upstash Redis (Vercel KV)
и **переживают cold start** инстансов. Если KV не подключён — код не падает,
а молча использует in-memory fallback (как в v1.0).

### Полный бэктест с драфтом
`/api/backtest?tournaments=...&full=1` — медленный, но точный режим: подтягивает
детали матчей и строит «скользящий» hero-pool из прошлых игр, поэтому
калибруется **в том числе фактор драфта**, а не только Elo/форма/H2H.

## Подключение Vercel KV (один раз)

1. Зайди в проект на Vercel → вкладка **Storage**
2. **Create Database** → выбери **Upstash for Redis** (есть бесплатный тир)
3. Назови (например `dota-kv`), создай, привяжи к проекту `dota-predictor`
4. Vercel сам добавит переменные окружения (`KV_REST_API_URL`,
   `KV_REST_API_TOKEN` и др.) в Production
5. Передеплой (любой коммит или Redeploy)

После этого калибровка будет постоянной.

## Как откалибровать

Открой один раз в браузере (id турниров — из главной страницы; пример ниже):

```
# Быстрая калибровка (Elo/форма/H2H):
https://dota-predictor.vercel.app/api/backtest?tournaments=19696,19543,19101

# Полная (медленно, +драфт) — добавь full=1:
https://dota-predictor.vercel.app/api/backtest?tournaments=19696,19543,19101&full=1
```

Ответ покажет `calibration` (A, B), `accuracy`, `logLoss`, `brier`,
`backtestedMatches` и `persisted: true`. После этого все прогнозы в UI будут
откалиброваны — в панели прогноза появится бейдж «✓ Откалибровано» с
переходом сырой→калиброванный.

## Замечания

- Полный режим ограничен 400 запросами деталей и 60 сек выполнения — для
  больших пулов он сэмплирует матчи равномерно.
- Калибровка глобальная (одна на всё приложение). Это нормально: она правит
  систематический сдвиг модели, а не специфику конкретной пары команд.
- Бэктест честный (walk-forward): фичи каждого матча считаются только по играм,
  сыгранным строго раньше — без утечки будущего.
