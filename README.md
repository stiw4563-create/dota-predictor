# DOTA·PROGNOSIS — прогноз матчей Dota 2

Веб-приложение для анализа live-матчей профессиональной Dota 2. Подгружает
текущие и недавние Tier 1 турниры через OpenDota, агрегирует статистику команд,
винрейты героев по сторонам с поправкой на свежесть/тир, и считает прогноз
победителя по взвешенной логистической модели.

**Стек:** Next.js 14 (App Router) + TypeScript + Tailwind, разворачивается на
Vercel в один клик. Без сторонних UI-библиотек, без БД, всё кэшируется в памяти
функций + через нативный fetch-кэш Next.

## Что умеет

- **Пул турниров.** Берётся 5 самых свежих Tier 1 турниров OpenDota, плюс
  активные `professional` турниры (квалификации с про-командами).
- **Live-матчи.** Поллинг `/api/live` раз в 20 секунд для активного турнира.
  При выборе live-матча — авто-заполнение команд и пиков по мере того,
  как они появляются в драфте; без перезагрузки страницы.
- **Ручной режим.** Любой матч из истории турнира можно выбрать как what-if:
  команды, сторона, пики — настраиваются вручную.
- **Кросс-патч агрегация.** Веса героев и матчей затухают экспоненциально
  по календарю (halflife = 60 дней), плюс множитель на тир турнира.
- **Интерпретируемая модель.** Прогноз = сигмоида суммы вкладов 6 факторов;
  каждый вклад отображается отдельным баром, чтобы видеть, что именно сдвинуло
  стрелку.

## Математическая модель

`logit(P_A) = Σ β_k · feature_k`, далее `P_A = sigmoid(logit)`.

| Фактор | Вес β | Что это |
|---|---|---|
| ΔElo | 2.3 | Разница Elo пула, нормированная на 400 пунктов. |
| ΔForm | 1.2 | Свежий винрейт с экспоненциальным затуханием по последним матчам. |
| H2H | 0.6 | Tanh-сжатая разница очных в пуле (защита от маленьких выборок). |
| ΔDraft | 2.5 | Сумма «винрейт героя на его стороне − 0.5», с Байес-сжатием при < 6 играх. |
| ΔHeroFit | 1.5 | Резерв под player-on-hero (в MVP = 0). |
| SideAdv | 1.8 | Винрейт Света в пуле − 0.5, со знаком по стороне A. |

Веса выбраны на основе доменной логики; для пост-калибровки нужно
логировать предсказания vs реальные исходы и тюнить через Platt scaling.

## Локальный запуск

```bash
npm install
npm run dev
# откроется http://localhost:3000 (или http://localhost:3001, если 3000 занят)
```

### Dev-мод с mock-данными

**По умолчанию** при локальной разработке используются mock-данные (фейковые турниры,
матчи, герои и live-игры). Это позволяет видеть весь интерфейс и функционал без
доступа к OpenDota API.

Mock-данные автоматически включаются когда:
- `NODE_ENV=development` (локальный `npm run dev`)
- OpenDota недоступен (сетевая ошибка, блокировка)

Если хочешь использовать **реальные данные** OpenDota вместо mock:

```bash
NEXT_PUBLIC_USE_MOCK=false npm run dev
```

### Про OpenDota API key

OpenDota **не требует** API ключа для публичных данных. Но если хочешь снять лимит
60 запросов в минуту:

1. Заведи ключ на [opendota.com/api-keys](https://www.opendota.com/api-keys)
2. Добавь в `lib/opendota.ts`:
   ```typescript
   const url = `${BASE}${path}?api_key=${process.env.OPENDOTA_API_KEY}`;
   ```
3. На Vercel добавь env переменную в Project Settings.

## Деплой на Vercel

1. Загрузи репо на GitHub / GitLab.
2. Импорт на [vercel.com/new](https://vercel.com/new).
3. Build command: `next build` (дефолт).
4. Output: `.next` (дефолт).
5. Никаких env-переменных не требуется; на Vercel используются реальные данные OpenDota.
6. Готово — приложение live на `*.vercel.app`.

При активной нагрузке:
- Добавить Redis-кэш (например Upstash) поверх in-memory.
- OpenDota API ключ (см. выше).

## Что НЕ сделано (roadmap)

- **Player-on-hero статистика.** OpenDota `/players/{id}/heroes` есть,
  можно по составу собрать bias. Сейчас фактор = 0.
- **Liquipedia интеграция.** Расписание ближайших матчей — требует
  серверного прокси с User-Agent; в MVP ограничились OpenDota.
- **Калибровка весов.** Веса сейчас доменная логика. Нужно логировать
  предсказания и подгонять через logistic regression.
- **Bans & draft order.** Сейчас только пики. Баны и порядок значат.
- **Player swap detection.** Не учитывает ростер-замены.

## Лицензия

Только для демо-целей. Данные принадлежат OpenDota и Valve.
