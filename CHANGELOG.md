# v0.3 — Hybrid OpenDota + Liquipedia

## Что изменилось

### Источники данных
- **Mock-режим теперь только по явному запросу.** `NEXT_PUBLIC_USE_MOCK=true`
  включает фейковые турниры. По умолчанию используются **реальные данные**
  OpenDota + Liquipedia.
- **Liquipedia как curated whitelist** Tier 1 турниров. Сначала мы тянем
  список актуальных S/A-Tier и Major турниров с Liquipedia
  (Portal:Tournaments), затем матчим имена с OpenDota по Jaccard-similarity,
  и берём только пересечение. Если Liquipedia недоступен — fallback на чистый
  OpenDota tier=premium фильтр.
- **Новый API:** `GET /api/team/[id]` — собирает имя, тэг (OpenDota) и текущий
  ростер (Liquipedia) команды.

### Модель
- **Clamping вкладов.** Каждый фактор теперь зажат в ±3 в логите (~95%
  индивидуального влияния), чтобы один шумный сигнал не давал 100%
  уверенности на маленькой выборке.
- **Вклад показывается в логит-единицах**, а не в «процентах», что было
  технически некорректно. Теперь +1 ≈ 73% уверенности, +2 ≈ 88%, +3 ≈ 95%.

### UI fixes
- Длинные названия турниров и команд теперь **переносятся в 2 строки**,
  а не обрезаются.
- Подробная ошибка + кнопка «↻ повторить», если турниры не загрузились
  (вместо общего «Не удалось»).

## Как развернуть после апгрейда

1. Закоммить и запушить.
2. **На Vercel убрать переменную `NEXT_PUBLIC_USE_MOCK`** (или поставить в
   `false`), чтобы пошли реальные данные.
3. Vercel пересоберёт автоматически.

Если хочется снова mock — добавить `NEXT_PUBLIC_USE_MOCK=true`.

## Чего не делал

- **Команда renaming через Liquipedia.** Я уже делаю identity clustering
  по составу из OpenDota (в `lib/identity.ts`). Liquipedia можно добавить
  как второй источник позже.
- **Расписание ближайших матчей.** Liquipedia это умеет (страница
  /Statistics конкретного турнира), но это отдельная итерация.
- **Полные имена с спецсимволами.** Если Liquipedia возвращает имя с
  юникодными хвостами, мы их пропускаем без транслитерации.
